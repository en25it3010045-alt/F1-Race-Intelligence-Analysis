01 / PROJECT OVERVIEW

TURNING RACE DATA
INTO INTELLIGENCE.

The Problem

Formula 1 performance information is spread across seasons, drivers, teams, circuits and race outcomes. Looking at these dimensions separately makes consistent comparison difficult.

The Approach

This project transforms the supplied race dataset into visual analytics that allow users to compare performance, identify trends and understand strategic and reliability patterns.

The Outcome

The website presents the same analytical story through data-driven visualisations built from the project dataset and designed to support clear, evidence-based insights.
